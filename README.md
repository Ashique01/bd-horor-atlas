# BD Horror Atlas

## 📖 Description
BD Horror Atlas is a community-driven web platform that allows users to explore, read, and submit horror stories collected from various regions of Bangladesh. Users can browse stories by division, submit their own tales, and interact with a secure admin panel for story management. The platform is designed to provide a seamless experience across both desktop and mobile devices.

## 🚀 Features
- User-friendly interface to browse horror stories by divisions of Bangladesh
- Story submission form for users to contribute their own ghost stories
- Admin login with JWT-based authentication and protected routes
- CRUD operations for managing stories via the admin dashboard
- Responsive design optimized for desktop and mobile devices
- Secure backend with Express.js, MongoDB, and JWT authentication
- CORS configuration for frontend-backend communication from localhost and production

## 🛠️ Tech Stack
- **Frontend:** React.js (with React Router, Tailwind CSS)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (using Mongoose ODM)
- **Authentication:** JWT (JSON Web Tokens)
- **Hosting:** Frontend hosted on Netlify, Backend hosted on Render/Other
